Manajemen Risiko Proyek

Risk Assessment & Mitigation Strategy

7 Skenario Lapangan
R1. Akun ATA Produksi Terlambat HIGH / MED

Dampak: Tertundanya rilis Flight Agent. Mitigasi: Follow up aktif ATA; siapkan konfigurasi agar siap uji harga riil segera.

R2. Kompleksitas API WebBeds Tinggi HIGH / HIGH

Dampak: Timeline hotel molor. Mitigasi: Review dokumen seawal mungkin di Sep; jangan jadikan 1.5 bulan sebagai komitmen kaku sebelum discovery tuntas.

R3. Alur DOKU Beda dengan Xendit MED / MED

Dampak: Penyesuaian webhook/callback. Mitigasi: Buat payment abstraction layer agar logika order tidak bergantung pada satu provider saja.

R4. Mitra KAI Telat Dipilih HIGH / HIGH

Dampak: Target live Januari gagal. Mitigasi: Kunci keputusan vendor maksimal akhir Oktober; pastikan sandbox & SLA usable.

R5. Kapasitas Terbatas Hanya 4 Orang HIGH / HIGH

Dampak: Bottleneck jika scope bertambah. Mitigasi: Pisahkan lead (Adrian Hotel, Setra DOKU), kunci 20% maintenance, stop scope creep.

R6. Incident Server Live / Bug Serius MED / HIGH

Dampak: Kapasitas dev terganggu. Mitigasi: Cadangkan kapasitas 20% harian; CTO turun langsung mengawal eskalasi cepat.

R7. Bottleneck di Mobile Engineer (Luthfy Tunggal) MED / MED

Dampak: Rilis app store tertahan. Mitigasi: Backend harus menstabilkan format API contract duluan sebelum Luthfy mulai merancang layar Flutter.

* Perhatian Utama Manajemen: R2 (WebBeds API), R4 (Mitra KAI), dan R5 (Kapasitas 4 orang) adalah 3 risiko berstatus High Impact / High Probability.
